# Einkaufsliste für echte Klänge

Vollständig — deckt alle 13 Geschichten ab. Dateien hier ablegen, Namen exakt
so schreiben.

**Die Synthese ist abgeschaltet.** Wo keine Datei liegt, bleibt es still. Die
Bibliothek zeigt an, wie viele der 52 Klänge schon da sind.

Quelle: [pixabay.com/sound-effects](https://pixabay.com/sound-effects/) — kein
Konto, keine Namensnennung, direkter Download.

**Effekte: 0,5 bis 3 Sekunden. Stille am Anfang wegschneiden.**

## Hochladen

[github.com/Stefan-33/GuteNacht](https://github.com/Stefan-33/GuteNacht) →
Ordner `public/sfx` → **Add file → Upload files** → reinziehen → **Commit
changes**. Netlify baut in etwa fünfzehn Sekunden neu.

Kein Git nötig, kein Programm auf dem Rechner. Auch einzeln möglich — jede
Datei wirkt sofort für sich.
